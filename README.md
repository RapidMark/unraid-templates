# RapidMark Unraid templates

Community Applications templates for containers built by RapidMark.

| app | image | source |
|-----|-------|--------|
| NNTmux | `rapidmark/nntmux` | https://github.com/RapidMark/NNTmux |

Manual install without CA: copy the XML from `templates/` to `/boot/config/plugins/dockerMan/templates-user/` on your Unraid box, then pick it from the template dropdown on Add Container.
